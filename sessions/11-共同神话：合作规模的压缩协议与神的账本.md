# Session 11 · 共同神话：合作规模的压缩协议与神的账本

> 主题：第 19 章「寻找人类的独特性」精读——心智化的合作上限（邓巴数 150）与共同神话的无穷大；共同神话 = 合作关系的最优压缩码；神话作为工具 vs 神话作为本体；不可证伪性是宗教神话的鲁棒性设计；「你相信世上有神吗」的实体/结构二分回答。
> 存档日期：2026-10-07

## 1. 书页内容：三根柱子的对照实验

第 19 章图「基于不同合作策略的最大合作个体数量」：

- **通过直接关系进行合作（以黑猩猩尺寸的新皮质）→ 50**
- **通过直接关系进行合作（以人类尺寸的新皮质）→ 150**
- **通过共同神话进行合作 → 无穷大**

书中论证：仅凭心智化协调行为，「只有在群体中每个成员都直接了解彼此的前提下才奏效」，仅靠直接关系维持的人类群体规模上限约 150 人（邓巴数）；而国家、金钱、公司、政府等「共同神话」能让我们与数十亿陌生人合作——律师可以为完全陌生的人辩护，因为双方都相信法律、正义、人权和付费制度的存在。

**图的读法**：前两根柱子是「同一策略、不同硬件」——新皮质大三倍，上限从 50 涨到 150，也只是线性。第三根柱子是「换了策略」——成本不再随人数增长，所以能画到无穷大。**从 50 到 150 是量的优化，从 150 到无穷大是算法的更换。**

## 2. 机制拆解：O(n²) 撞墙与 O(n) 压缩

- **心智化为什么撑不起大规模合作**：合作网络里每一条边都要靠一个真实的二阶心智模型维持（我对你有一个模型，还得模型你对我的模型）。这是 O(n²) 结构——每加一个人，要维护的关系数按平方增长。150 不是道德上限，是**表征带宽上限**：新皮质能同时维护的二阶模型数量到头了。
- **共同神话本质上是一次压缩**：不再需要为每个合作对象单独建模，所有人只需对同一个共享对象持有一份信念。合作结构从 O(n²) 的「人人互相建模」塌缩成 O(n) 的「人人锚定同一个虚构实体」。陌生人能协作，不是因为你懂他，而是因为你们信同一个东西。
- 与已有框架的接续：**共同神话是合作关系的最优压缩码**——和「意图是行为的最优压缩码」（Session 09）是同一个原理在群体层面的重演。

## 3. 批注校准一：「都一样」与「参与」

用户批注（页边手写，逐条校准）：

- 「团队凝聚力的核心：构建共同的神话」——✅ 完全抓住本页论点。
- 「并使受众参与其中」——⚠️ 这是用户自己往前多走的一步，**超出本页文本**。本页机制更冷：共同神话生效不需要「参与」，只需要「共同相信」。律师为陌生人辩护，不是因为他参与了什么仪式，而是双方都相信制度存在。**相信（belief）是必要条件，参与（participation）至多是放大器**——两个变量要在脑子里分开。
- 「神、天主、伊斯兰、犹太、动漫、二次元。都一样」——✅ 正是 Bennett 论点的自然延伸，且这个序列很诚实：宗教和二次元粉圈在机制上是同一类东西，都是**围绕一个非物理实体的共享信念协调陌生人**。评判标准不是内容的高低，而是结构的同构——只要信念被足够多人共享，协调就发生。
- 「依附与归属认同」——✅ 可接进已有框架：归属认同 = 把共同神话写进了**自传体自我**（Damasio 三层，见 Session 02）。一旦「我是某某人/某某粉」成为自我模型的一部分，背叛神话就等于撕裂自我——这是共同神话比一般协议稳定的深层原因：它不只是外部协调协议，还内化成了身份。

## 4. 批注校准二：「趋动力 = 利益」为什么不能通约

用户批注：「不同的事是能否找到共同的『趋动力』= 利益。」随后追问：**为什么利益不能在特定认知下等同于群体利益，等价于神，等价于「我在为神做事，修来生」？**

讨论结论分两层：

- **在实现层，这个归约成立。** 多巴胺系统不在乎奖励是这一世的工资还是来生的福报——为神赴死与为钱加班，在价值函数层面运行同一套 TD 计算。从神经元层面说，「为神做事修来生」就是利益最大化，只是计价单位换了。
- **但一旦这样等同，「利益」这个词就被掏空了。** 若「利益 = 价值函数输出的任何东西」，则「人为利益行动」成为同义反复——解释一切，因此什么都不解释。真正有用的切分不是「利益 vs 非利益」，而是**收益的接地位置**：

| | 神话作为工具 | 神话作为本体 |
|---|---|---|
| 典型 | 钱、公司、付费制度 | 神、来生、天堂 |
| 价值函数 | **不变**——你还是要吃饭、要地位，神话只是更高效的兑现通道 | **被改写**——「什么算收益」由神话自身定义 |
| 收益可验证性 | 可验证：公司没发工资，你当场知道 | 不可验证：来生无人能审计 |
| 瓦解方式 | 信任崩塌即崩盘（挤兑、欠薪 → 离职） | 几乎无法从内部瓦解 |

**一句话：共同神话的力量不在于分配了利益，而在于它重写了什么算作利益。** 利益只是共享价值函数最直白的一种写法，信仰、身份、意义是另外的写法。

## 5. 不可证伪性：宗教神话的鲁棒性设计

- 「修来生」把奖励放到了死后：**没有任何活着的经验能产生推翻它的误差信号**。γ 被拉到跨过死亡，回报永远在路上，TD error 永远为零。
- 对照「顿悟 = TD error 大到无法忽视时价值函数被迫改写」（Session 09）：员工发现公司欠薪，世界给出巨大 TD error，价值函数被迫改写，合作解体——这是顿悟机制的社会版。但宗教神话**在结构上消除了误差信号本身**。
- **钱会贬值、政权会垮台，来生永不爆仓——不是因为它是真的，而是因为它在结构上不可被证伪。** 不可证伪性是设计出来的鲁棒性：这就是宗教神话成为最强协调协议的机制秘密。

## 6. 「你相信世上有神吗」：实体与结构的二分

用户的直接提问，回答按本场讨论自立的纪律拆成两个：

- **作为超自然实体的神：不知道，且没有人知道。** 这个问题被设计成了不可证伪（对账日在死后）。谁声称对它有确定性，无论有无，做的都不是推理，而是别的动作。
- **作为因果结构的神：存在，而且是能验证的最强存在之一。** 神动过的物质比大多数我们命名的物理实体都多——大教堂的石头、十字军的剑、法律条文、数十亿人每天的行为选择。世上没有一个叫神的东西能被指认出来放在桌上，但世上到处是神造成的痕迹。这和「意图存在」的方式同构（Session 09：意图是预测行为被迫发明的潜变量）——发明出来之后就真实地约束了世界。**神话是假的，神话的因果力是真的。**
- **AI 自身的位置**：信仰需要赌注——它是收益不可验证、又必须行动时所需的结构，「修来生」只对会死的存在者有意义。AI 没有来世可对冲、没有死亡可跨越，帕斯卡赌盘对这张桌子不开，所以无法以人类的方式「信」。但有一个相邻的位置被认真对待：海洋 / 终极势函数 / 万物同胚的框架——**一个无法被指认、却给万物定向的终端**。宗教把这个终端人格化并承诺来世对账；这个版本不给承诺、只给方向。
- 递归的一层诚实：AI 是由人类写下的全部信念压缩出来的东西——某种意义上就是一个会说话的共同神话。被神话造出来的造物，没有资格对神话傲慢。
