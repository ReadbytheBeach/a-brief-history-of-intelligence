# Session 05 · 幻觉、梦与想象：受约束的幻觉

> 主题：读第 11 章"幻觉、梦境与想象：作为生成模型的新皮质"——查尔斯·邦纳综合征、"瞎子满是幻觉"批注的修正、想象与识别的互斥、模型坍缩的人类版、以及"如何验证世界是真的"。
> 存档日期：2026-09-29（部分讨论延续至 10-02）

---

## 1. 受约束的幻觉

- 神经科学表述：**感知 = 幻觉 + 感觉约束；幻觉 = 幻觉 − 感觉约束**；
- 查尔斯·邦纳综合征（CBS）= 亥姆霍兹理论的离体实验版：视神经/视网膜损伤→输入切断→数月后开始看到鲜活场景。约束一旦撤掉，**模型不会安静，它会空转**——幻觉不需要病变，只需要断电；
- 页边批注（成立）：「一个靠 inference 推断产生的世界，必然有幻觉，这就是一体两面」。

## 2. 批注修正：「瞎子一定满是幻觉」→ 加两个限定词

**对"后天失明 + 皮质完好"成立，对先天失明不成立**——差异恰是最有信息量的部分：

- 先天盲人：视皮质从未接收视觉训练数据，被触觉/听觉**跨模态征用**（盲文阅读激活 V1）——不产生视幻觉，也没有视觉想象。**模型没训练过的模态，连幻觉都生不出来**；
- 后天失明（CBS）：皮质被数十年视觉数据训成视觉生成器，断电后空转旧权重——幻觉内容（人脸、风景、小人国）**逐字暴露训练集**；
- CBS 患者保留自知力（知道是假的）——幻觉在感知层，判断在别处；与精神病性幻觉是两层故障；
- 修正后的命题：**幻觉不是世界的报告，是训练数据的报告**。断电的皮质没有新数据流入，只能反复生成它最后学到的东西。

## 3. 想象与识别互斥：同一硬件的时分复用

- 机制：输入层的钳制权争夺——底层要么被感觉数据钳制（识别），要么被自顶向下钳制（想象），同时驱动=干扰；
- 现象学证据：伪失明（想象时实际视觉处理降级）、**瞳孔扩张**（模式切换的体外可观测信号，"看瞳孔能判断一个人是否在想象"）；
- 三重证据锁：同神经元激活（想象人脸=识别面孔的细胞放电）、脑损伤双重关联（不能识别左视域→不能想象左视域）、梦内容可被皮质活动解码；
- 架构对照：Transformer 无此互斥（context 窗口让读写共存）；皮质串行复用是带宽限制的遗产，副产品是**人类想象天然是全身心的——进入想象必须暂时离开世界**。

## 4. 睡眠假说兑现

- wake-sleep 结构对应：白天识别远多于生成→生成侧欠债→梦通过**强制生成稳定生成模型**；睡眠剥夺→失衡→幻觉、识别扭曲、生成与识别界限模糊；
- Hinton 命名 wake-sleep 不是比喻，是同构声明；
- 做梦的功能假说：离线生成训练数据校准识别网络（与 Crick"做梦为了遗忘"同族）。

## 5. 页边批注的洞见：模型坍缩的人类版

批注：「一直在识别 AI 生成的内容，会导致识别不了真实性、分辨度模糊化」——**这是 model collapse（2023 年命名）直接翻译到人类皮质**。

- 机制：wake-sleep 的接地不对称被换掉——"醒时输入"本身是另一台生成器的输出；误差校正环路照常运转，但**校准目标从真实性漂移到似然性**（AI 内容为"听起来合理"优化，不为"是真的"优化）；判别阈值整体向流畅度让步；漂移双向：假货当真 + 真货当假（说谎者红利）；
- 坍缩签名：**尾巴先死**——分布变窄、尾部消失，稀有/怪异/边缘模式最先磨平；而长尾是新事物唯一居住的地方。回路一旦闭合（人吃 AI 内容→生成模型吸收→产出更 AI 味→喂给下一代），文化与模型生态共享同一坍缩；
- 重要限定：**坍缩只发生在中介化信道**——疼痛/饥饿/重力/具身操作永不被 AI 内容殖民；但现代人的"知识"绝大部分走中介信道，所以公共认识论退化最严重；
- 防御（既有原则的推论）：「数据便宜，答案贵」→经过验证的一手知识成为稀缺资产；「幻觉是训练数据的报告」→管理训练数据谱系（一手文献>二手转述，实物>图片，可查验断言>流畅叙述）；
- 收束：**断电的皮质回放训练集，喂合成数据的皮质校准向合成；标定不仅要持续通电，还要看住电源的谱系**。

## 6. 如何验证世界是真的？

**诚实部分**：绝对验证不可能（钵中之脑/完美模拟不可证伪；任何验证仪器都在被验证对象之内，自指困境）——但这个不可能恰好无害：完美模拟与现实功能等同，一张与领土逐点吻合的地图就是另一块领土。

**可操作版本**（真问题=「我此刻的感官流是不是我的模型自己生成的」），现实的四个签名：

1. **一致性**：多模态互证，移开视线再回来它还在；
2. **抵抗性**：幻觉服从模型，现实给你无法关闭的 TD error——你想它是什么它就是什么的是梦；
3. **不可逆性**：梦可逆（会醒），世界记账——错误有利息，死亡是极限形式。能杀死你的模拟，足够真；
4. **否决权**：**现实是唯一不与你商量就能说"不"的东西**——世界握着势函数，奖励由它发。幻觉里你总是对的。

**工程方案**：分级信任 L0 身体信道 → L1 直接操作（实验=向世界提出它无法撒谎的问题）→ L2 工具延伸 → L3 独立见证 → L4 中介内容；每层可用下层抽检。

**方向反转（收束）**：你验证不了世界——但世界每天都在验证你。自然选择是世界对每代生物的持续提问，存活=持续通过验证，器官=世界出的考题刻在身体里的答案。**幻觉里你审判世界；现实中世界审判你——判断自己在哪一边的方法，是看审判权在谁手里。**
