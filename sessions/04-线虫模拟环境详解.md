## 1. 模拟世界：环境场的叠加

线虫生活在一个由多个标量场叠加的 2D 平面中。每个场对应书中的一个感官通道：

| 环境场 | 感官通道 | 数学模型 | 生物学对应 |
|--------|----------|----------|-----------|
| 温度场 | 温觉 | 多个高斯分布叠加 | 线虫的 AFD 热敏神经元 |
| CO₂ 场 | 嗅觉 | 高斯衰减（来自食物源） | AWC 化学感受器 |
| 光场 | 视觉 | 距离平方反比衰减 | 避光行为 |
| 危险场 | 触觉/嗅觉 | 高斯衰减（来自捕食者） | ASH 伤害感受器 |

**温度场的代码实现**（`core/world.py`）：

```python
# 1 个中心舒适区 + 1-2 个热点 + 1-2 个冷点
self._temp_centers = np.array([
    [width/2, height/2],           # 舒适中心
    [0.8*width, 0.8*height],       # 热点
    [0.2*width, 0.2*height],       # 冷点
])
self._temp_amps = np.array([0, +15, -10])
self._temp_sigmas = np.array([30, 15, 15])

# 高斯叠加：T(x,y) = optimal + Σ A_i * exp(-d²/(2σ²))
d2 = np.sum((self._temp_centers - [x, y])**2, axis=1)
return optimal_temp + np.sum(amps * np.exp(-d2/(2*sigmas**2)))
```

这种叠加方式让线虫的"家"不是单一的点，而是一个**梯度景观**——线虫通过比较身体两侧的温度差来判断移动方向，而不是直接感知绝对坐标。

## 2. 两侧对称的传感器布局

线虫有 **6 个传感器**，呈 3 对左右对称分布：

```
              heading 方向
                 ↑
       光L ●        ● 光R   (±60°, dist=0.5r)
      温L  ●          ● 温R  (±45°, dist=0.8r)
      化L   ●        ●  化R  (±30°, dist=0.6r)
                 ◯          ← 身体中心
```

**关键设计**：线虫不知道自己的绝对位置，只知道**两侧差异**。这模拟了真实生物的**趋化性（taxis）**——不是 GPS 定位，而是梯度跟踪。

传感器位置通过旋转矩阵计算（`core/worm_body.py`）：

```python
angles = heading + sensor_angles      # [45°, -45°, 30°, -30°, 60°, -60°]
offsets = np.column_stack((
    dists * np.cos(angles),
    dists * np.sin(angles)
))
global_pos = body_position + offsets
```

## 3. 观测向量：11 维感知输入

线虫的"大脑"接收的是一个 **11 维向量**（启用情感引擎时为 18 维）：

| 维度 | 内容 | 归一化方式 | 生物学意义 |
|------|------|-----------|-----------|
| 0 | 温度左 | `(temp_L - 20) / 17.5` | 左侧温感 |
| 1 | 温度右 | `(temp_R - 20) / 17.5` | 右侧温感 |
| 2 | 温度差 | `(temp_L - temp_R) / 35` | 梯度方向信号 |
| 3 | CO₂ 左 | 原始值 [0,1] | 左侧化学感受 |
| 4 | CO₂ 右 | 原始值 [0,1] | 右侧化学感受 |
| 5 | CO₂ 差 | `CO2_L - CO2_R` | 化学趋向性方向 |
| 6 | 光左 | 原始值 [0,1] | 左侧光感受 |
| 7 | 光右 | 原始值 [0,1] | 右侧光感受 |
| 8 | 光差 | `light_L - light_R` | 避光方向 |
| 9 | 触觉 | 0/1 | 碰撞检测 |
| 10 | 能量 | `energy / 100` | 内部状态（饥饿/饱腹）|

**为什么用差值？** 因为线虫没有绝对坐标系，它只能感知"左边比右边暖"或"右边比左边亮"，然后决定向左转还是向右转。这与书中描述的两侧对称神经系统完全一致。

## 4. 动态效价：CO₂ 的"饥饿反转"

这是情感算法的核心设计之一。CO₂ 对同一线虫来说，**效价不是固定的**，而是取决于内部能量状态：

```python
def co2_valence_reward(self, co2, energy):
    if energy < 50:   # 饥饿
        # 高 CO₂ = 好事（食物方向）→ 正奖励
        return reward_weight * co2 * (1 - energy/50) * 2.0
    else:             # 饱腹
        # 高 CO₂ = 坏事（缺氧/拥挤）→ 负奖励
        return reward_weight * (-co2 * (energy/50 - 1) * 1.5)
```

这对应书中的**神经调质系统**：饥饿时多巴胺升高，使 CO₂ 变得"诱人"；饱腹时血清素升高，使 CO₂ 变得"令人厌恶"。同一个外部刺激，因内部状态不同而产生完全相反的效价——这就是情感算法的本质。

## 5. 奖励函数的七组分

总奖励由 7 个独立组分相加：

| 组分 | 权重 | 触发条件 | 情感调制 |
|------|------|----------|----------|
| 温度舒适 | 1.0 | 接近 20°C | 肾上腺素×0.3 |
| CO₂ 效价 | 2.0 | 饥饿/饱腹反转 | 多巴胺×0.5 |
| 能量 | 1.0 | 吃到食物 | 多巴胺×0.5 |
| 生存 | 0.1 | 每步存活 | 血清素×0.3 |
| 碰撞 | -5.0 | 撞障碍物 | 肾上腺素×0.8 |
| 危险 | -3.0 | 靠近捕食者 | 肾上腺素×0.8 |
| 光 | -0.5 | 暴露在光下 | 不变 |

**情感调制**：当情感引擎启用时，每个奖励组分乘以一个由神经调质水平决定的系数。例如，高肾上腺素会让碰撞和危险的惩罚变得"更痛"，这是一种**注意力放大**机制。

## 6. 情感状态在可视化中的映射

当启用情感引擎时，线虫内部还有一个 7 维情感向量：

| 维度 | 含义 | 正常范围 |
|------|------|----------|
| 多巴胺 | "好事将近" | ~0.05（基线） |
| 血清素 | "满足感" | ~0.10（基线） |
| 肾上腺素 | "威胁" | ~0.00（基线） |
| 效价 | 正/负情绪 | [-1, 1] |
| 唤醒度 | 激活水平 | [0, 1] |
| 情感状态 | 四类离散状态 | 0-3 |
| 慢性压力 | 长期负效价累积 | [0, 1] |

**四类情感状态**（书中的 2D 情感空间）：

```
            高唤醒（arousal ≥ 0.5）
              ↑
  效价 < 0    |    效价 ≥ 0
  ESCAPE     |    EXPLOIT
  逃避       |    探索/利用
  高速低转向 |    低速高转向
              |
   ───────────┼──────────→ 效价
              |
  DISTRESS   |    SATIATION
  痛苦       |    满足
  几乎不动   |    静止休息
              ↓
            低唤醒
```

**慢性压力 → 快感缺失（anhedonia）**：当线虫长期处于 DISTRESS 状态时，`chronic_stress` 累积，导致食物奖励被乘以一个衰减因子（最高衰减到 0.3）。这对应书中的抑郁症模型——即使环境中有食物，也无法产生快感。

## 7. 完整感知-动作闭环

```
环境场（温度/CO₂/光/危险）
    ↓
6 个传感器读取 → 11 维观测向量
    ↓
情感引擎（多巴胺/血清素/肾上腺素）→ 7 维情感向量
    ↓
奖励函数（效价调制）→ scalar reward
    ↓
RL 策略网络 → [speed, turn] 动作
    ↓
线虫移动 → 新位置 → 循环
```

这就是书中最核心的命题：**智能不是大脑内部的孤立计算，而是身体、情感与环境的三方互动**。线虫的"智能"不在于它的策略网络有多复杂，而在于它的奖励函数能够根据内部状态（饥饿/饱腹、安全/危险）动态地重新评估外部世界——这正是情感的计算本质。
