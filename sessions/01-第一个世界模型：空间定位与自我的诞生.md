# Session 01 · 第一个世界模型：空间定位与自我的诞生

> 主题：读《智能简史》第 9 章——头部方向神经元、内侧皮质（海马体前身）、自我-世界的首次分离；用机器人学词汇逐条对账。
> 存档日期：2026-09-29

## 1. 头部方向神经元：生物版 IMU 融合

**结论/要点**：书上"整合视觉和前庭输入，以形成神经指南针"一句，批注"（IMU）"不只是类比，是机制级同构。

- 前庭系统 ≈ IMU：半规管测角速度（陀螺仪），耳石测线加速度与重力方向（加速度计），六轴配置；
- 视觉 ≈ 视觉里程计/地标校正：纯前庭积分会漂移（与纯 IMU 积分漂移同因），视觉地标周期性纠偏——互补滤波器；
- 维持机制：头朝向细胞组成**环状吸引子网络（ring attractor）**，黑暗中无视觉输入时靠内部递推维持朝向估计——生物版航位推算（dead reckoning）；
- MicroDuck 对照：总线上的 imu_to_dxl（ID 200）干的是这件事的最小子集。

## 2. 为什么是两个：差分推拉，不是冗余备份

**结论/要点**：脊椎动物的前庭器官成对（左右内耳各一套：三个半规管 + 耳石器），原因是差分测量架构，不是容错冗余。

- 半规管按**共面对**工作：左水平↔右水平、LARP（左前-右后）、RALP（右前-左后）；
- 推拉式编码（push-pull）：转头时对中一侧兴奋、一侧抑制，大脑读**两侧差值**——灵敏度翻倍、共模噪声对消（体温/血压/振动）、静息基调（~70-100 spikes/s）上双向调制；
- 与双眼（视差测距）不同，前庭的"两个"是两套正交坐标系的差分对置。

## 3. 单 IMU 的根本盲区：等价原理问题

**结论/要点**：任何加速度计都无法区分"倾斜"与"水平加速"（重力惯性合力，爱因斯坦等价原理的生物版）——融合不是优化，是必需。

- 生物解法：半规管积分姿态 + 耳石器合力 + 视觉地标 + 小脑前向模型，把合力**分解**为重力分量与运动分量；双侧对比提供额外约束；
- 机器人翻译：单 IMU 测刚体姿态够用，歧义靠 gyro 融合 + 视觉/运动学约束补；两个 IMU 只在冗余容错、非刚性形变、**分段状态**（躯干 IMU 测不了足底接触——正是电子皮肤的生态位）时值得加；
- 完整对照：IMU=前庭，皮肤=触觉，Dynamixel 位置/电流回读=本体感觉兼职。

## 4. 内侧皮质：第一个 allocentric 表征

**结论/要点**：鱼类内侧皮质（海马体前身）里的三类神经元 = 后来海马三件套，关键突破是表征从"我感受到什么"解耦为"世界是什么样的"。

| 鱼类内侧皮质 | 哺乳动物海马体 | 机器人学类比 |
|---|---|---|
| 特定位置激活 | 位置细胞（place cells） | 定位（localization） |
| 水箱边缘激活 | 边界细胞（border cells） | 地图边界/障碍表征 |
| 特定朝向激活 | 头朝向细胞 | 航向状态估计 |

- allocentric（非自我中心）：事物相对于其他事物的位置，而非相对于"我此刻的视角"——这是"第一个世界模型"批注成立的判据：脱离即时感知、可查询、可外推的内部表征；
- Bennett 暗线：海马空间地图是后来新皮质模拟能力的机器原型——先学会建模空间，再学会建模一切。

## 5. 自我的出生证明：传出副本

**结论/要点**："某物朝我游来 vs 我朝某物游去"的区分需要**传出副本（efference copy）/再传入原则**——运动指令发出时复制一份给感知系统，减去自己造成的感官变化，残差才归因外部世界。

- 控制理论表述：状态观测器必须同时知道测量值 y 和控制量 u；卡尔曼滤波器收不到 u 会把自激运动算进外部状态；
- 核心论断：「**自我不是先验存在的实体，而是为了正确感知世界而被迫发明的一个变量**」——世界模型建到一半，方程里缺的那一项就是"我"。

## 6. 批注校准：Damasio 三层阶梯

用户批注：「自我意识首先要在物理空间中正确定义自己的位置，才能决定下一步往哪里去」。用 Damasio 分层校准：

1. **原初自我（proto-self）**：身体状态实时映射——本体感觉、内脏、姿态；
2. **核心自我（core self）**：当下"我与此物的关系"——空间自我定位在此层，=地图上"你在这里"标记，承重墙但只是小蓝点；
3. **自传体自我（autobiographical self）**：跨时间叙事自我——很久以后的事。

- 补充：只有位置不够，还需朝向——位姿（pose）= 位置 + 航向，位置细胞与头朝向细胞长在同一个回路里不是巧合；
- 演化链：空间定位 → 离线预演（replay/preplay）→ 规划/想象 → 时间定位 → 叙事自我。自我意识的完整历史=小蓝点从空间地图扩散到时间轴的过程。
