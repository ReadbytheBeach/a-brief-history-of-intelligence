## 1. 走路的例子：模型只在失败时显形

- 左脚放下却没感觉到地面→立刻察觉：符合预期的感知是**静默**的，只有意外浮上意识；
- 推论：**你意识到的世界其实是世界的残差**——顺畅的现实不占用意识带宽，意识是预测误差的显示器；专注时"忘记脚的感觉"=误差为零无需上报；
- 幻觉与伪失明之所以能发生：意识本来就不住在数据里，住在误差里。

## 2. 表 11.1：预测目标的三次升级

| 阶段 | 预测什么 | 机器 |
|---|---|---|
| 早期两侧对称动物 | 反射激活（神经元 A 的激活先于 B） | 反射环路（Hebb 式时序关联） |
| 早期脊椎动物 | 未来的奖励 | 皮质 + 基底节 Critic |
| 早期哺乳动物 | **所有感觉数据** | 新皮质 |

第三行为什么是关键一跃：

1. **监督信号的带宽革命**：奖励稀疏（一天没几口），感觉流免费、无限、稠密——每一毫秒世界都在免费出考卷。学习速率被带宽决定而非被运气决定；
2. **为未知的未来任务买保险**：只为奖励预测→模型只保留与当前奖励相关的细节；但未来任务需要哪些细节现在不知道。预测一切=把世界联合分布压进权重，任何未来奖励函数都能直接查询。**压缩即智能的生物学原版**——PPL 是本质指标，因为它对应世界模型的保真度。

## 3. 批注校准：World Model 的任务书

页边批注：「World Model 要做的事就是建立一种新皮质建模，采用其模拟重建现实世界的预测。」校准——两条 AI 路线之争与大脑的答案：

- **MuZero 路线（价值等价）**：只预测与奖励相关的未来，不求还原世界——省算力但模型窄；
- **Genie/Dreamer 路线（稠密重建）**：预测像素级未来——贵但通用；
- **大脑的答案**：**预测一切，但按相关性给误差加权**（precision weighting，注意力=误差的权重分配器）；

修订版任务书：**不是"重建现实世界"，而是"持续预测全部感觉流，让相关性权重决定重建保真度"**。重建是手段，预测是目的；保真是可分配的预算，不是均匀的目标。

另一个关键词「**持续**」：新皮质永远在线、比实时快地预跑（接住的每个球都是预测替你接的）——LLM 是按需生成，大脑是主动预跑。

## 4. 延伸：鸭子新皮质 · 边缘-云端架构方案（v0）

由表 11.1 第四行直接推出的施工图（正式设计文档将入 my-microduck docs/）：

| 层 | 位置 | 频率/视野 | 预测什么 | 生物对应 |
|---|---|---|---|---|
| L0 反射层 | robotd（端） | 50Hz+ / <0.5s | 姿态、接触、滑移 | 脊髓/脑干 |
| L1 新皮质芽 | 端侧小世界模型 | 10–20Hz / 0.5–2s | 下一秒的自身感觉流（85 维 obs + IMU） | 鱼的内侧皮质 |
| L2 大世界模型 | DGX Spark（家） | 离线 / 长时程 | 情景 rollout、策略演练 | 哺乳动物新皮质 |
| L3 语义层 | 云/手机 LLM | 秒级 / 任务 | 目标条件化下发 | 前额叶/语言区 |

- **L1 可行性**：Dreamer 式迷你 RSSM（GRU+小 MLP，百万级参数 INT8），RK3566 跑得动；三功能=异常检测（surprise 触发反射）/短程安全 rollout/数据分诊（只上传高误差片段=惊奇事件簿）；
- **日夜节律（wake-sleep 机器人版）**：白天端侧栈生活+记录惊奇 → 夜晚充电时回传事件簿 → DGX 训练大 WM、imagination 里练策略、梦里评估 → 蒸馏回端侧 → 走政策通道 OTA（验签+shadow mode 再放量的单向门）。端侧=海马体快记，云端=新皮质慢固化；
- **降级序列**：每层失效退到更老一层，永远不存在"无脑"状态；
- **MVP 原则**：从"预测自己"开始（预测 2 秒后的自身传感流），与五亿年前那条鱼同构——先自我模型，再物体，再他者。
